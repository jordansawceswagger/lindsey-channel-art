# Filling in the catalog (for Lindsey / Holly)

Open `catalog-template.csv` in Google Sheets or Excel. **One row per painting, every painting since 2005**, including the ones that sold. Sold work goes on the site marked Sold. Twenty years of finished paintings is what makes a buyer trust a $2,000 price.

| Column | What to put | Example of the format |
|---|---|---|
| title | The painting's real title | |
| year | Year finished | 2014 |
| type | `original` or `print` | original |
| status | `available`, `sold`, `collection` (owned by someone, not for sale), or `nfs` (you're keeping it) | sold |
| medium | What it's painted on | Oil on canvas |
| dimensions | Size | 24 x 30 in |
| price | Only if available | $1,800 |
| print_kind | Only for prints: what kind | Giclee, numbered of 50 |
| description | One or two sentences **in Lindsey's words**: what it is, where, who, why | |
| image | Leave blank (Steve's photo goes in as `paintings/<title>.jpg`) | |
| slug | Leave blank | |

Don't know a year? Leave it blank. Better blank than guessed.
